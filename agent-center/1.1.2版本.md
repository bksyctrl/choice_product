# 🚀 AgentCenter v1.1.2 开发需求说明书

## 1. 版本定位
本版本核心目标是**打破品类限制**与**量化产品潜力**。通过跨品类视觉驱动逻辑和 AI 综合打分算法，提升选品的科学性与跨平台迁移效率。

---

## 2. 方向一：爆款跨品类 (Cross-Category Intelligence)
**核心思路**：本方向严格遵循以下三大选品原则：
1.  **印花工厂基建**：以工厂现有的柔性生产线为锚点，所有选出的爆款元素必须能够轻易复用到现有的生产工艺中（如热转印、数码直喷、丝网印等）。
2.  **POD (Print on Demand) 按需定制**：脱离传统囤货思维，寻找能够激发消费者个性化定制欲望、适合小批量多批次生产的设计载体。
3.  **销售力由视觉驱动**：摒弃复杂的材质和功能比拼，优先爬取 FastMoss 等平台中视觉属性极强的大品类。再基于风格下钻至具体小品类，提取出高商业价值的爆款视觉设计元素，最终赋能并平移至手机壳、T恤、帆布包、马克杯等 POD 定制化产线。

### 2.2 爬取思路与数据采集标准
为了支撑上述的品类下钻地图，我们的爬虫引擎必须严格执行以下数据采集策略：
*   **数据源设定**：所有数据必须爬取自 FastMoss 平台下对应品类的**销量榜单**。
*   **核心过滤门槛**：为保证视觉风格已经过一定的市场验证，剔除偶然因素，单品的**销量必须 > 100** 才能入库分析。
*   **增补关键指标**：除了基础指标外，必须爬取并记录**销售环比**数据，以帮助我们识别该视觉风格是处于爆发上升期还是衰退期。
*   **字段一致性**：为确保系统向下兼容，其余所有爬取的字段必须与现有的 `fastmoss_search_product` 结构保持完全一致。

### 2.3 网页设计实现
*   **左侧菜单**：新增【跨品类数据】栏目。
*   **筛选功能**：复用原有筛选器，支持按大类/二级品类/小品类级联过滤。
*   **核心按钮**：列表操作列新增【提取插画】按钮，点击后触发 AI 抠图/元素识别逻辑。

## 4. AI 综合打分算法 (AI Scoring Engine)
旨在寻找“潜力爆发产品”，而非简单的销量排行。

### 4.1 综合得分公式
**Score = 销量分(35) + 评分分(25) + 热度分(25) + 趋势分(15)**

### 4.2 维度计算明细
1.  **销量分 (35%)**
    *   `norm30d = log10(30天销量+1) / log10(类目最大30天销量+1)`
    *   `Penalty = |norm30d - 0.5| * 0.67`
    *   `Final = norm30d * (1 - Penalty) * 2 * 35`
2.  **评分分 (25%)**
    *   `Final = (评分 / 5) * 100 * 25` (默认值 3.5)
3.  **热度分 (25%)**
    *   `normVideo = log10(视频数+1) / log10(类目最大视频数+1)`
    *   使用同上销量分的 Penalty 惩罚函数。
4.  **趋势分 (15%)**
    *   `Ratio = 7天销量归一化 / 30天销量归一化`
    *   `Final = min(1, Ratio) * 100 * 15`

### 4.3 风控红线 (触发直降 0 分)
*   评分 < 3.0。
*   均价不在 [$1, $100] 区间内。
*   **疑似刷单**：30 天销量 = 0 且总销量 > 0。

### 4.4 决策结论
*   **≥75 分**：推荐上架
*   **50~74 分**：观察等待
*   **<50 分**：暂不上架

## 5. 网页实现思路建议

### 5.1 视觉化仪表盘 (Dashboard)
*   **分值气泡**：在列表页以颜色区分分数等级（绿、黄、灰）。
*   **权重拆解**：点击分数可查看弹出式蜘蛛网图或条形图，展示四个维度的原始表现。

### 5.2 交互增强
*   **趋势微型图 (Sparklines)**：在销量占比列嵌入微型折线图，直观反映 7 天/28 天的走势对比。
*   **提取插画预览**：点击提取后，在侧边栏显示 AI 处理后的素材层，支持一键保存。

### 5.3 全量回算流程
*   **基准值动态化**：在数据同步阶段，实时更新每个 `category_id` 下的最大销量和视频数。
*   **异步重算**：在后台管理页面提供【触发全量回算】入口，通过多线程异步更新全表 score 字段。
